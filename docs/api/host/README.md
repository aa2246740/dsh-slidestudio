# SlideStudio Host API shared by standalone and plugin

Generated by `npm run docs:generate` from `scripts/quality/api-contracts.mjs`.

Source: `packages/dsh-slides-host/src/routes.ts`. This is a local API, not a public cloud endpoint.

| Method | Route | Behavior |
| --- | --- | --- |
| GET | `/slides/health` | Read selected-provider readiness and produce gates |
| GET | `/slides/models` | Read the current runtime-backed model roster, without invented fallback entries |
| GET | `/slides/providers` | Read supplier-scoped provider status; never expose API keys |
| POST | `/slides/assistant-intent` | Classify the next turn without granting write permission |
| POST | `/slides/sessions` | Start a real provider-backed session; may incur provider usage |
| POST | `/slides/sessions/{sessionId}/turn` | Send a scoped continuous-conversation turn |
| POST | `/slides/sessions/{sessionId}/stop` | Stop without authorizing or completing unfinished edits |
| GET | `/slides/state/{sessionId}` | Read durable session state and verified page evidence |

Request/response fields are in [openapi.json](openapi.json). Native/Host coverage is explicitly limited to these critical interfaces. Provider execution requires user authorization; documentation generation never calls a provider.
