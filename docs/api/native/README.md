# Native editor API, critical HTTP interfaces

Generated by `npm run docs:generate` from `scripts/quality/api-contracts.mjs`.

Source: `apps/native-web/src/server.mjs`. This is a local API, not a public cloud endpoint.

| Method | Route | Behavior |
| --- | --- | --- |
| GET | `/api/health` | Read editor/project health and capability status |
| GET | `/api/projects` | Discover local PPTD projects |
| POST | `/api/open` | Open a validated local project in the requesting tab |
| POST | `/api/command` | Apply a native command under project and tab write guards |
| GET | `/api/versions` | List recoverable PPTD versions |
| POST | `/api/versions` | Save a recoverable version |
| POST | `/api/versions/restore` | Restore a validated version with existing write-lock rules |
| POST | `/api/export` | Export the editable deck or current page; output includes the existing export report |
| GET | `/api/diagnostics` | Local request counters without project identities or content |

Request/response fields are in [openapi.json](openapi.json). Native/Host coverage is explicitly limited to these critical interfaces. Provider execution requires user authorization; documentation generation never calls a provider.
